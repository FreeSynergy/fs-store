# fs-store

Object store for FreeSynergy programs: AS2 envelope + domain content + activity log, UUIDv7, embedded Turso behind a trait (ADR 0019, 0020, 0027, 0042).

NOTE: GitHub repo FreeSynergy/fs-store exists from the old version — this is the new one, local until the owner decides.
